# 4주차 프로젝트 운영안

## 1. 교육 개요

- **교육 기간:** 2026년 8월 10일 ~ 8월 14일
- **교육 시간:** 1일 8시간, 총 40시간
- **운영 형태:** 팀 프로젝트 중심
- **주요 환경:** Ubuntu 24.04, ROS 2 Jazzy, Python, OpenCV, Gazebo Harmonic, OpenMANIPULATOR-X, MoveIt 2, FastAPI 또는 pywebview
- **주간 목표:** 1~3주차에 학습한 로봇 제어, 영상처리, AI 인식, 3차원 환경 모델링과 Dashboard 기술을 활용하여 하나의 완성된 로봇 응용 시스템을 기획·구현·검증·발표한다.

4주차에는 새로운 기술을 폭넓게 설명하기보다 학생이 선택한 프로젝트를 실제로 완성하는 데 집중한다. 강사는 공통 아키텍처, 기본 코드, 문제 해결 방법과 안전 기준을 제공하고 학생은 생성형 AI를 이용하여 필요한 코드를 만들고 직접 검증한다.

---

## 2. 프로젝트 운영 원칙

- 팀당 2~4명을 권장한다.
- 프로젝트는 반드시 ROS 2 Node를 2개 이상 포함한다.
- OpenMANIPULATOR-X 또는 Gazebo Manipulator를 사용한다.
- OpenCV 또는 AI Vision 기능을 최소 1개 이상 포함한다.
- MoveIt, JointTrajectory 또는 Gripper Action 중 하나 이상을 사용한다.
- Dashboard 또는 상태 표시 UI를 포함한다.
- 모든 팀은 실제 장비용 코드와 Gazebo 검증 경로를 함께 준비한다.
- 필수 기능과 확장 기능을 분리하여 최소 완성본을 우선 구현한다.
- 생성형 AI가 만든 코드는 실행 결과와 오류 수정 내역을 기록한다.
- 산업 안전 기능으로 오해되지 않도록 단안 Depth와 AI 인식의 한계를 명시한다.

---

## 3. 공통 시스템 아키텍처

```text
Camera / Gazebo
      ↓
Vision Node
  ├─ HSV·Contour
  ├─ Edge·Hough·ORB
  ├─ YOLO Detection·Segmentation
  ├─ Depth Anything V2 Metric
  ├─ MoGe-2 ViT-S
  └─ Robot TF + TSDF
      ↓
Perception Result Topic
      ↓
Decision / State Machine Node
      ↓
Manipulator Control
  ├─ JointTrajectory
  ├─ Gripper Action
  └─ MoveIt Planning
      ↓
Dashboard
  ├─ Camera Stream
  ├─ Robot State
  ├─ Detection Status
  ├─ Command Buttons
  └─ Logs and Results
```

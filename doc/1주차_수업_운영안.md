# 1주차 수업 운영안

---

## 1. 교육 개요

- **교육 기간:** 2026년 7월 20일 ~ 7월 24일
- **교육 시간:** 1일 8시간, 총 40시간
- **주요 환경:** Windows 11, WSL2 Ubuntu 24.04, ROS 2 Jazzy, Python, VS Code, Git/GitHub, RViz2
- **교육 방식:** 개념 설명 → 짧은 코드 실습 → 실행·오류 분석 → 미니 과제 → 결과 공유
- **주간 목표:** ROS 2 통신, 실행 구조, 좌표계, 로봇 모델링의 기초를 익혀 2주차 OpenMANIPULATOR-X와 3주차 비전·MoveIt 수업을 수행할 수 있는 기반을 갖춘다.

1주차는 단순히 ROS 2 명령어를 익히는 과정이 아니라, 이후 모든 프로젝트에서 반복해서 사용하는 Node, Topic, Service, Action, Parameter, Launch, TF2, URDF/Xacro의 역할을 연결해 이해하는 데 중점을 둔다.

## 2. 주간 학습 흐름

```text
Ubuntu·WSL·Git 환경
        ↓
ROS 2 CLI와 Node Graph
        ↓
Topic·Service·Action·Parameter
        ↓
사용자 정의 Interface
        ↓
QoS·DDS·Executor·Callback Group
        ↓
Launch·Namespace·다중 Node
        ↓
TF2·URDF·Xacro·RViz2
        ↓
OpenMANIPULATOR-X·MoveIt·Vision 수업 기반
```

## 3. 주간 목표

- WSL Ubuntu 24.04, VS Code Remote WSL, Git/GitHub, ROS 2 Jazzy 환경을 구성한다.
- ROS 2의 Node, Topic, Service, Action, Parameter 차이를 설명하고 직접 구현한다.
- 사용자 정의 `msg`, `srv`, `action` 인터페이스를 패키지에서 빌드하고 사용한다.
- Launch, Namespace, QoS, DDS/RMW가 다중 Node 실행에 미치는 영향을 이해한다.
- SingleThreadedExecutor와 MultiThreadedExecutor, Callback Group의 차이를 이해한다.
- TF2로 좌표계를 발행·조회하고 URDF/Xacro 모델을 RViz2에서 검증한다.
- Header Stamp와 Frame ID가 센서·TF·MoveIt 통합에서 중요한 이유를 이해한다.
- 생성형 AI로 코드 초안을 만들되 ROS 1 혼입, 메시지 타입 오류, 잘못된 API를 직접 검증한다.

## 5. 공통 AI 활용 방식

생성형 AI를 다음 목적으로 사용한다.

- ROS 2 Python Node 초안 생성
- Launch File 초안 생성
- 사용자 정의 Interface 구조 제안
- 오류 메시지 분석
- 코드 리팩터링
- README 작성

AI 생성 코드 검토 항목:

- ROS 1 API가 섞였는가
- Jazzy에서 존재하지 않는 API를 사용했는가
- Topic 이름과 Message Type이 일치하는가
- `rclpy.init`, `spin`, `shutdown` 흐름이 올바른가
- Callback 내부에 Blocking 작업이 있는가
- Frame ID와 Timestamp가 빠졌는가
- Exception 처리와 Resource 정리가 있는가

## 8. 2·3·4주차 연결

```text
1주차 ROS 2 기본기
        ↓
2주차 OpenMANIPULATOR-X·MoveIt·Gazebo
        ↓
3주차 OpenCV·YOLO·Metric Depth·TSDF
        ↓
4주차 팀별 통합 프로젝트
```

1주차의 각 기술은 다음과 같이 재사용된다.

| 1주차 기술 | 후속 활용 |
| --- | --- |
| Topic | Joint State, Camera, Detection, Depth, PointCloud |
| Service | 장비 설정, 상태 요청, 작업 명령 |
| Action | Gripper, Trajectory, MoveIt 실행 |
| Parameter | HSV, Confidence, Depth Range, Safety Margin |
| QoS | Camera와 Sensor Topic |
| Executor·Callback Group | Vision, Robot, Dashboard 동시 실행 |
| TF2 | Camera·Object·Base 좌표 변환 |
| URDF·Xacro | Robot Model, Camera Link, Collision Geometry |
| Launch | 전체 시스템 통합 실행 |

이 문서는 1주차 실제 수업 내용을 유지하면서, 이후 OpenMANIPULATOR-X 제어, MoveIt Planning Scene, Gazebo Camera, YOLO Segmentation, Metric Depth, TSDF와 OctoMap 수업으로 연결되도록 보강한 운영안이다.

# 4주차 프로젝트 샘플 20선

## 1. 문서 목적

이 문서는 1~3주차 동안 학습한 ROS 2, OpenCV, OpenMANIPULATOR-X, MoveIt 2, YOLO Segmentation, Metric Depth, Robot TF, TSDF, OctoMap, FastAPI와 pywebview를 활용하여 학생들이 4주차에 수행할 수 있는 프로젝트 예시 20가지를 제시한다.

각 프로젝트는 5일 안에 최소 기능을 완성할 수 있도록 범위를 제한했으며, 팀의 수준에 따라 확장 기능을 추가할 수 있다.

---

## 2. 프로젝트 선택 기준

프로젝트를 선택할 때 다음을 확인한다.

- 실제 OpenMANIPULATOR-X 또는 Gazebo에서 검증 가능한가
- Camera 입력과 Vision 처리가 포함되는가
- Robot Action이 명확한가
- 5일 안에 최소 완성본을 만들 수 있는가
- Dashboard 또는 결과 시각화가 가능한가
- 실패 조건과 안전 정지 조건을 정의할 수 있는가

## 5. 최소 범위와 확장 범위 구분 예시

```text
Camera 입력
→ Target 검출
→ Robot 한 가지 동작
```

### 확장 범위

```text
Metric 3D 위치
→ Planning Scene 갱신
→ MoveIt 경로 계획
→ Pick and Place
→ Dashboard와 기록
```

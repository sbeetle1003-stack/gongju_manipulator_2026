# ROS 2 기반 로봇팔 및 비전 제어 교육과정

## 교육과정 개요

* 교육기간: 총 4주
* 교육구성

  * 1주차: ROS 2 및 로봇 제어 기초교육
  * 2주차: OpenMANIPULATOR-X 제어 및 Gazebo Sim 실습
  * 3주차: OpenCV 기반 로봇팔 비전 제어
  * 4주차: 팀별 종합 프로젝트

---

## 1주차: ROS 2 및 로봇 제어 기초

| 일차  | 교육 내용 |
| --- | --- |
| 1일차 | Ubuntu 24.04 WSL, VS Code Remote WSL, Git/GitHub, ROS 2 Jazzy 설치 및 ROS 2 CLI·RQt·Turtlesim 실습 |
| 2일차 | ROS 2 노드/토픽/서비스/액션 구조 이해, Publisher·Subscriber 구현, Header 메시지와 Launch 실행 실습 |
| 3일차 | DDS/RMW와 QoS 설정, 사용자 정의 msg/srv 인터페이스 빌드, Service Server/Client, 파라미터 콜백·AsyncParameterClient 실습 |
| 4일차 | Fibonacci Action Server/Client, feedback/result/cancel/abort 처리, namespace 기반 다중 노드 및 정적·동적 TF 실습 |
| 5일차 | TF2 Listener 기반 좌표 조회 및 추종, URDF 링크·조인트·물리 속성, Xacro 매크로와 RViz2 모델 검증 실습 |

## 2주차: OpenMANIPULATOR-X 제어 및 시뮬레이션

| 일차  | 교육 내용                                |
| --- | ------------------------------------ |
| 1일차 | ROBOTIS Docs(OpenMANIPULATOR-X) 기준으로 구동 전 자세 점검, U2D2/OpenCR 연결, `open_manipulator_x.launch.py` 실행 및 ros2_control 구성 이해 |
| 2일차 | ROBOTIS Docs(OpenMANIPULATOR-X) 실습 흐름에 따라 JointTrajectory/Gripper 제어, 키보드 teleop, GUI 조작으로 실제 로봇팔 기본 동작과 상태 피드백 확인 |
| 3일차 | ROBOTIS Docs(OpenMANIPULATOR-X) MoveIt 2 흐름 기반으로 하드웨어 연동 플래닝 실습, Planning Group(arm/gripper), goal state(init/home/open/close) 운용 |
| 4일차 | Gazebo Sim 공식 튜토리얼 기반으로 `open_manipulator_x_gazebo.launch.py`와 `use_sim:=true` 환경 구성, 시뮬레이터에서 MoveIt·teleop·GUI 연동 실습 |
| 5일차 | Gazebo Sim 공식 tutorial(`spawn_urdf`, `sdf_worlds`, `moving_robot`, `sensors`, `gui`) 기반으로 URDF/Xacro 스폰, SDF 월드·플러그인·센서 구성, 토픽 기반 제어 검증 |

## 3주차: OpenCV 기반 로봇팔 비전 제어

| 일차  | 교육 내용                        |
| --- | ---------------------------- |
| 1일차 | 기존 매니퓰레이터 프로젝트 기반 카메라 파이프라인 점검(`cv_bridge`, camera_info, 왜곡보정) 및 OpenCV 전처리(이진화/윤곽/ROI)로 인식 안정화 기준 수립 |
| 2일차 | ArUco/객체 인식 실습: 마커 dictionary 선택, 검출 파라미터 튜닝, `solvePnP` 기반 pose 추정(rvec/tvec), 마커 ID별 작업 태스크 매핑 |
| 3일차 | 카메라 좌표계에서 검출한 pose를 로봇 기준 좌표계로 변환하는 TF2 체인 구성(`camera_link`→`base_link`), 동적 TF 발행 노드 작성 및 RViz2 검증 |
| 4일차 | MoveIt 연동 실습: 인식 결과를 Planning Scene 충돌체로 반영(ADD/REMOVE/ATTACH/DETACH), 장애물 회피 경로 계획과 재계획 트리거 구현 |
| 5일차 | 통합 운영안: 카메라 인식→TF 발행→목표점 계산→MoveIt 실행의 End-to-End 데모 구현, 오검출/프레임 지연/좌표 오차 디버깅 및 성능 점검 |
